**Stack Liquid Glass** is a glassmorphism-flavored Hugo theme — a liquid-glass redesign of [Hugo Theme Stack](https://github.com/CaiJimmy/hugo-theme-stack), with a near-zero JavaScript pipeline, light/dark mode, and built-in JSON search.

This site documents how to install and configure the theme.

## Sections

- [Getting Started](/getting-started/) — install the theme and write your first `hugo.toml`.
- [Configuration](/configuration/) — full reference for `[params]`, menus, and social links.
- [Widgets](/widgets/) — sidebar widgets available on the homepage and on pages.
- [Shortcodes](/shortcodes/) — extra shortcodes the theme provides.
- [FAQ](/faq/) — common questions and gotchas.

The Japanese version of this site is at [/ja/](/ja/).

For the source code, see the [GitHub repository](https://github.com/rin2yh/hugo-theme-stack-liquid-glass).

**Stack Liquid Glass** は、[Hugo Theme Stack](https://github.com/CaiJimmy/hugo-theme-stack) をベースに、ガラス質感（glassmorphism）の UI とほぼ JS なしの配信パイプラインに作り変えた Hugo テーマです。ライト/ダーク切替、`/index.json` ベースの全文検索、TOC、Mermaid、外部 URL 投稿、日本語 i18n に対応しています。

このサイトはテーマのインストールと設定方法をまとめたドキュメントです。

## セクション

- [はじめに](/ja/getting-started/) — テーマのインストールと最小 `hugo.toml`。
- [設定](/ja/configuration/) — `[params]`、メニュー、ソーシャルリンクの完全リファレンス。
- [ウィジェット](/ja/widgets/) — ホームページとページに配置できるサイドバーウィジェット。
- [ショートコード](/ja/shortcodes/) — テーマが提供する追加のショートコード。
- [FAQ](/ja/faq/) — よくある質問と注意点。

英語版は [/](/) にあります。

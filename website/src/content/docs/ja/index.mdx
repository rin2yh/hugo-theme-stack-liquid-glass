**Stack Liquid Glass** は、ほぼ JS なしの配信パイプラインに作り変えた Hugo テーマです。ライト/ダーク切替、`/index.json` ベースの全文検索、TOC、Mermaid、外部 URL 投稿、日本語 i18n に対応しています。

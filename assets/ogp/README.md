# OGP (Twitter Card) images

Assets for generating a per-article OGP image at Hugo build time.

## How it works

1. `base.png` — the fixed background (themed gradient + glass panel + accent
   bar). A **brand-neutral** default, generated by `cmd/ogp` and committed.
2. `layouts/partials/ogp-image.html` — overlays the page title onto `base.png`
   with the `images.Text` filter and returns the generated image's absolute URL.
3. `layouts/partials/head/opengraph.html` — when a page has no `image` /
   `cover.image`, this generated image is used for `og:image` / `twitter:image`
   (an explicit image still wins, and the site default
   `defaultImage.opengraph.src` is the final fallback).

CI (Hugo extended) builds the images from just this `base.png` and the bundled
font, so the Go toolchain is not required to build the site.

## Replacing the background

Dropping your own `assets/ogp/base.png` in the site overrides the theme's
default via Hugo's union filesystem, letting you swap in a branded background.
Align it with the title-drawing coordinates in
`layouts/partials/ogp-image.html` (below the accent bar, above the bottom-left
branding).

## Regenerating the background

Colors, layout, and branding are produced by `cmd/ogp/main.go`. The theme root
has no `go.mod`, so run it from the `cmd/ogp` directory:

```sh
cd cmd/ogp

# Brand-neutral default bundled with the theme
go run . -out ../../assets/ogp/base.png -font ../../assets/ogp/NotoSansJP-Bold.ttf

# Add a site name in the bottom-left
go run . -site "My Blog"

# Add an avatar (png/jpg/webp) too
go run . -site "My Blog" -avatar /path/to/avatar.png
```

## Font

`NotoSansJP-Bold.ttf` is a `wght=700` static instance of Google Fonts' Noto
Sans JP (variable font). Licensed under the
[SIL Open Font License 1.1](./NotoSansJP-LICENSE.txt).

This is the demo site for **Stack Liquid Glass**, a Hugo theme that reimagines the classic Stack layout with glassmorphism surfaces, soft gradients, and a near-zero JavaScript pipeline.

Browse the sample posts to see how the theme handles long-form writing, table of contents, Mermaid diagrams, and external link entries. Use the search widget on the homepage to try the built-in `/index.json` full-text search.

Toggle between light and dark mode from the sidebar — the theme persists your choice and respects your system preference on first load.
